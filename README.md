# GridVibe - Premium Intelligence Dashboard

GridVibe is a cutting-edge, interactive analytics dashboard designed to transform raw data into visually stunning and actionable insights. Built with modern web technologies and a focus on premium user experience, GridVibe offers seamless drag-and-drop customization, deep data drill-down capabilities, and beautiful responsive themes.

## 🚀 Key Features

- **Real-Time CSV Parsing**: Powered by [PapaParse](https://www.papaparse.com/), simply drag and drop your raw CSV data and watch it instantly transform into a dynamic dashboard. String columns and number columns are automatically mapped.
- **Interactive Drill-Down Analytics**: Click on any data point in the main charts to instantly filter the entire dashboard—including tables and sub-charts—for deep-dive analysis.
- **Drag & Drop Layouts**: Powered by [SortableJS](https://sortablejs.github.io/Sortable/), effortlessly rearrange your dashboard widgets (KPIs, Charts, Tables) to suit your workflow.
- **Dynamic Theming System**: Switch between stunning themes (Midnight, Light Glass, Neon Cyber) that sync perfectly down to the granular Chart.js rendering level.
- **Advanced Export Options**: Export your filtered insights back to CSV format, or generate a clean, print-ready PDF report of your current view.

## 🛠️ Technology Stack

- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Visualization**: [Chart.js](https://www.chartjs.org/) for responsive, canvas-based data visualizations.
- **Data Parsing**: [PapaParse](https://www.papaparse.com/) for lightning-fast CSV processing.
- **Interactivity**: [SortableJS](https://sortablejs.github.io/Sortable/) for smooth drag-and-drop grid management.
- **Icons**: [Lucide Icons](https://lucide.dev/) for crisp, lightweight SVG iconography.

## 📥 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ttallbamatuyu/gridvibe.git
   ```
2. **Run Locally:**
   Simply open `index.html` in any modern web browser. No complex build tools or backend servers are required!
3. **Load Data:**
   Use the "CSV Upload" zone to drop your own data, or click the "Sample Data" button to instantly explore the dashboard's capabilities.
